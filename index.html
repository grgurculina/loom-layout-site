What it does

Six things that save you a lot of dragging.

Each one works on its own. Together they keep your desk the same, every day.

⌨

Keyboard snapping

Halves, quarters, thirds, maximize, center, and the previous size. One shortcut per placement, and every shortcut can be changed.

⇲

Drag to snap

Drag a window to an edge or corner. A preview shows where it will land before you let go. Turn it off if you don't want it.

▦

Locked grid

Lock a screen to a grid of 2 side by side, 2 stacked, 2 × 2, or your own split. Drop a window on one cell, or on the border between two.

⟲

Remembers your layout

Each display setup keeps its own memory. Unplug your external monitor and reconnect it later, and your windows come back where they were.

★

Named layouts

Save an arrangement under a name, restore it from the menu, or let it restore automatically when a display setup connects.

⇥

Window switcher

An alt-tab style switcher that lists windows by most recently used. Hold ⌃⌥ and press Tab to move through them.

Dragging

Drag, and the screen tells you where it will land.

Start dragging by a window's title bar. Move toward an edge or a corner and a preview shows the result. Releasing applies it.

Edges & corners Locked: 2 side by side Locked: 2 × 2

Drop near the left edge to fill the left half. Top edge maximizes, bottom edge fills the bottom half, and corners fill a quarter.

Getting started

Up and running in about two minutes.

1

Install

Open LoomLayout-1.0.0.dmg and drag LoomLayout into Applications. Start it from there. The first time, right-click it and choose Open if macOS blocks it, because this build isn't notarized.

2

Allow Accessibility

LoomLayout moves other apps' windows, so macOS needs your permission. Go to System Settings → Privacy & Security → Accessibility, turn LoomLayout on, then quit and reopen it. This is the only permission it asks for.

3

Try a shortcut

Click a window and press ⌃⌥←. It moves to the left half. Press ⌃⌥Return to maximize it.

4

Tune it

Open LoomLayout's menu bar icon, then Settings. Pick a grid for each screen under Setup, change any shortcut under Shortcuts, and decide which apps it remembers under Apps.

Your data

Everything stays on your Mac.

LoomLayout has no account and sends nothing to anyone, as described in its privacy policy.

  • Layouts and settings are saved in ~/Library/Application Support/MagicTab/state.json. A damaged file is kept as a backup, never deleted.
  • The placement log (~/Library/Logs/MagicTab/placements.csv) records app IDs and window rectangles only. It never contains window titles, and it's rotated at 1 MB. Delete it any time.
  • Permissions: only Accessibility, which is needed to move windows.

Questions

Common questions

The menu bar icon shows, but nothing happens.

Accessibility access isn't granted for this copy. Open System Settings → Privacy & Security → Accessibility. If LoomLayout is listed but still asks for access, remove it with −, add /Applications/LoomLayout.app with +, turn it on, and reopen LoomLayout.

I updated LoomLayout and it asked for Accessibility again.

Each new build has a new signature, and macOS treats it as a different app. Approve the copy in Applications again.

A window doesn't move, or lands somewhere unexpected.

Check Settings → Apps. An app switched off with Remember here won't be placed. Some apps also have a minimum window size, and a snap smaller than that leaves the window at its minimum.

A shortcut does nothing.

Another app may already use that combination. Choose a different shortcut in Settings → Shortcuts.

What doesn't it do?

Windows on other Spaces and in full-screen mode aren't moved. Dragging starts from the title bar (the top 80 points of a window). ⌘Tab stays with macOS. Shortcuts are single key presses, so true two-key chords aren't used.
