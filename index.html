LoomLayout

A window manager for macOS that lives in your menu bar. Snap windows with the keyboard, drag them onto a grid, save layouts and switch windows quickly.

Download for macOS

Version 1.0.0 · macOS 13 (Ventura) or later · .dmg file

Features

Keyboard snapping

Halves, quarters, thirds, maximize, center, and back to the previous size.

Drag to snap

Drag a window to an edge, a corner, or a grid locked to a screen.

Split screens

Split a screen into 2 or 4 parts and remember which window sits where.

Saved layouts

Save a layout under a name and restore it from the menu or when displays reconnect.

Window switcher

An alt-tab style switcher, most recently used first.

Custom shortcuts

Change any shortcut in Settings. Nothing is hard-coded.

Install

  1. Download LoomLayout-1.0.0.dmg and open it.
  2. Drag LoomLayout into Applications.
  3. Open LoomLayout. The first time, right-click the app and choose Open if macOS blocks it.
  4. Grant Accessibility access under System Settings → Privacy & Security → Accessibility, then quit and reopen LoomLayout.

LoomLayout needs Accessibility access to move other apps' windows. It requests nothing else.
