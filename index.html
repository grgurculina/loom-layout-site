What it does

Six things you stop doing by hand.

Each one works on its own. Together, your desk looks the way you left it, every day.

01

Keyboard snapping

Halves, quarters, thirds, maximize, center, and back to the previous size. Move a window to another display with one shortcut. Every key can be changed in Settings.

Left halfTop rightBottom right
02

Drag to snap

Drop a window on an edge or corner. A preview shows where it lands before you let go.

03

Locked grid

Lock a screen to 2 side by side, 2 stacked, a 2 × 2 grid, or your own split. Drop on a cell or on a border between two.

04

Remembers each display setup

"MacBook alone" and "MacBook + monitor" are separate memories. Unplug the monitor, plug it back in, and your windows return to the spots they had.

EditorChatDocs
05

Named layouts

Save an arrangement under a name. Restore it from the menu, or let it come back automatically when a display setup connects.

06

Window switcher

An alt-tab style switcher that lists windows by most recently used. Hold ⌃⌥ and tap Tab to move through them.

Questions

Quick answers.

The menu bar icon shows, but nothing happens.

Accessibility access isn't granted for this copy. Open System Settings → Privacy & Security → Accessibility. If LoomLayout is listed but still asks, remove it with −, add /Applications/LoomLayout.app with +, turn it on, and reopen LoomLayout.

macOS says the app can't be opened.

This build isn't notarized yet. Right-click LoomLayout in Applications and choose Open, then confirm once.

I updated LoomLayout and it asked for Accessibility again.

Each new build has a new signature, so macOS treats it as a different app. Approve the copy in Applications again.

A window doesn't move, or lands somewhere unexpected.

Check Settings → Apps. An app switched off under Remember here won't be placed. Some apps also have a minimum window size, and a snap smaller than that leaves the window at its minimum.

What doesn't it do?

Windows on other Spaces and in full-screen mode aren't moved. Dragging starts from the title bar (the top 80 points of a window). ⌘Tab stays with macOS. Shortcuts are single key presses, so true two-key chords aren't used.
